# Cleric preparation and domain grants

User ruling: adopt 2024 preparation counts for prepared casters only, delivering
Cleric first. Bard and every other class retain their current model and creation
choices. This is not an edition-wide migration: existing domain selection timing
and authored domain spell lists remain unchanged.

Source: https://www.dndbeyond.com/sources/dnd/br-2024/character-classes#Cleric
The Cleric table supplies four preparations at level one, independent of Wisdom;
automatic domain spells do not use that count. The preparation column is separate
from SpellsKnown. Supported spell options remain the executable Cleric catalog.
Domain spells and bonus cantrips are granted even when their execution is deferred.
Light deliberately has no Cast profile until objects can be targeted/illuminated.

The existing spell-choice contract carries the chosen preparations. Domain-aware
requirements exclude already granted spells/cantrips from paid selections. At
finalization, the existing KnownSpells access list contains preparations plus
resolved domain grants, deduplicated; the level record retains chosen inputs.
This keeps one casting authority and preserves the existing session Cast reader.
Existing saved sheets are not rewritten or trimmed by this creation change.
Changing preparation after a long rest and a distinct private-sheet presentation
of selected versus always-prepared spells are subsequent work, not claimed here.

Advancement uses the preparation count delta, can select any supported spell level
within available slots, and adds newly available domain grants separately.
