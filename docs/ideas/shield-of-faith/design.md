# Shield of Faith

2014 rules: https://www.dndbeyond.com/spells/2248-shield-of-faith (Basic Rules p.275).
Level-one bonus-action spell; choose a creature within 60 feet, including self;
+2 AC with concentration up to ten minutes. No attack, save, healing or dice.
Use the existing bonus-action casting history and payment path used by Healing Word.
A leveled action spell and this spell cannot share a turn, in either order;
an action cantrip or ordinary weapon attack remains compatible.

The target holds a source-qualified condition modifying the existing AC chain.
Equal-potency castings do not stack, but independent caster provenance survives
so ending one does not remove another. Concentration owns lifetime (100 subsequent
caster turn ends, existing clock convention), failed saves, replacement, and
incapacitation. Long rest removes protection. Existing CharacterData AC and
condition facts carry the result; no bespoke API rules or wire fields.

Preparation, component enforcement and out-of-combat timed expiration remain
within the existing spell-system scope; this change does not add those systems.
